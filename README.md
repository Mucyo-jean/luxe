# Project Title

## LuxeStore – Online Shopping Store

---

# Project Objective

The purpose of this project was to design and develop a simple e-commerce website using Wix, a No-Code platform. The project demonstrates the practical application of e-commerce website design principles, user experience concepts, and GitHub Markdown documentation.

---

# Platform Used

- Wix Website Builder

---

# Project Description

LuxeStore is an online shopping website developed using Wix. The platform provides customers with a simple and user-friendly experience for browsing products, learning about the business, and contacting customer support.

The website was designed to offer smooth navigation while implementing the fundamental features of an e-commerce website.

---

# Features Implemented

## Home Page

The Home page includes:

- Store name (LuxeStore)

- Featured products
- Navigation menu
- Responsive layout
